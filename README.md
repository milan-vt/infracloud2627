## Structuur

```
infracloud2627/
├── README.md          # dit overzicht
├── Week 1/
├── Week 2/
└── Week 3/
    ├── README.md      # briefing van de week
    └── oefening1.py … oefening7.py
```

- Eén map per lesweek: `Week <nummer>/`.
- De briefing van een week staat in de `README.md` van die map.
- Eén bestand per opdracht: `oefening<nummer>.py`, genummerd zoals in de briefing.
- Datasets en exportbestanden worden door de scripts gegenereerd en horen niet thuis in de repository.
